# شجرة العائلة (Arbre Généalogique Familial)

Application communautaire multi-plateforme (Flutter Web & Android) conçue pour aider les familles dispersées à construire, vérifier et préserver leur arbre généalogique de manière collaborative et sécurisée.

---

## 🌟 Fonctionnalités Principales

- **Langue & Orientations Nativement Arabe (RTL)** : Interface conçue pour l'arabe avec support i18n extensible.
- **Visualisation Interactive de l'Arbre** : Support Zoom / Pan, vues par génération et filtres de recherche.
- **Gestion des Profils & Relations** : Fiches détaillées des membres (nom complet, naissance/décès, parents, conjoints, enfants).
- **Vérification Communautaire** : Système de vote et d'approbation par les membres/modérateurs de la famille pour chaque modification.
- **Documents Officiels & Justificatifs** : Gestion des actes de naissance et livrets de famille pour certifier les liens.
- **Multi-plateforme & Synchronisation** : Déploiement initial sur le Web (Flutter Web) et mobile Android via API REST / GraphQL sur-mesure.
